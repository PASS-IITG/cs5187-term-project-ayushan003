## 2. Stage 0: Gap Analysis Specification

### 2.1 Mathematical Formulation of the Gap
$$	ext{Exported} = \{ f \mid f \in 	ext{nm}(	ext{libX.a}) \land 	ext{type}(f) \in \{'T', 'W'\} \}$$
$$	ext{Declared} = \{ f \mid f \in 	ext{AST}(	ext{Headers}) \land 	ext{kind}(f) = 	ext{FUNCTION\_DECL} \}$$
$$	ext{Public API} = 	ext{Exported} \cap 	ext{Declared}$$
$$	ext{Executed} = \{ f \in 	ext{Public API} \mid 	ext{count}(f) > 0 	ext{ in } 	ext{llvm-cov}(	ext{Corpus}) \}$$
$$\mathbf{GAP} = 	ext{Public API} \setminus 	ext{Executed}$$

### 2.2 Schema of `gap.json`
```json
{
  "library": "libarchive",
  "api_total": 247,
  "reached_total": 23,
  "gap_total": 224,
  "gap_ratio": 0.9069,
  "by_prefix": {
    "archive_write": { "api": 78, "reached": 0, "gap": 78 },
    "archive_entry": { "api": 62, "reached": 3, "gap": 59 },
    "archive_read": { "api": 41, "reached": 20, "gap": 21 },
    "archive_match": { "api": 14, "reached": 0, "gap": 14 }

    }
```

## 3. Stage 1: API Modeling & Role Heuristics

`gapharn.apimodel` traverses C abstract syntax trees using Python bindings to `libclang`. It extracts structural metadata and classifies every symbol into functional roles:

| Role Category | Heuristic Identification Pattern | Examples in libarchive |
| :--- | :--- | :--- |
| **Initializer** | Returns pointer to opaque handle ($T^*$), accepts no handle as parameter, name matches `*_new`, `*_open`, `*_init`. | `archive_write_new()`, `archive_read_new()`, `archive_entry_new()` |
| **Data-Entry** | Accepts handle parameter + contiguous buffer pointer (`void*`, `char*`) and length (`size_t`), or filename string. | `archive_write_open_memory()`, `archive_write_data()` |
| **Destructor** | Accepts handle parameter, returns `void` or `int`, name matches `*_free`, `*_close`. | `archive_write_close()`, `archive_write_free()`, `archive_entry_free()` |
| **Processor** | Accepts initialized handle, mutates state or processes metadata, returns status integer. | `archive_write_set_format_by_name()`, `archive_write_header()` |
| **Auxiliary** | Standalone utility functions, attribute getters, stateless converters. | `archive_version_number()`, `archive_error_string()` |

### 3.1 Producer-Consumer Graph
A directed graph $G = (V, E)$ where $V = 	ext{Public API}$:
$$E = \{ (u, v) \mid 	ext{ReturnType}(u) = T^* \land T^* \in 	ext{ParamTypes}(v) \}$$
For any unexercised gap function $g \in \mathbf{GAP}$, the minimal invocation chain is derived via shortest-path Breadth-First Search (BFS) from any Initializer node $u_{	ext{init}}$ to $g$.

## 4. Stage 2: Synthesis Engine Architecture

### 4.1 G1: Rule-Based Harness Structure (C Code Generation)
Every G1 harness implements the standard `LLVMFuzzerTestOneInput` signature and enforces defensive lifecycle contracts:

```c
#include <archive.h>
#include <archive_entry.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

// Format and filter tables mined from macros and enums
static const char *FMTS[] = {"pax", "ustar", "gnutar", "v7tar", "cpio", "zip", "7zip", "iso9660"};
static const char *FLTS[] = {"none", "gzip", "bzip2", "xz", "lzma", "zstd"};
#define NELEMS(a) (sizeof(a)/sizeof((a)[0]))

int LLVMFuzzerTestOneInput(const uint8_t *d, size_t n) {
    if (n < 4) return 0; // Guard against insufficient data

    // Dynamic parameter selection from fuzz input bytes
    const char *fmt = FMTS[d[0] % NELEMS(FMTS)];
    const char *flt = FLTS[d[1] % NELEMS(FLTS)];
    size_t name_len = d[2] % 64;
    d += 3; n -= 3;
    if (name_len >= n) return 0;

    char entry_name[65];
    memcpy(entry_name, d, name_len);
    entry_name[name_len] = ' ';
    d += name_len; n -= name_len;

    // Phase 1: Initialize handle (O4 check)
    struct archive *a = archive_write_new();
    if (!a) return 0;

    // Phase 2: Configuration & format attachment
    if (archive_write_set_format_by_name(a, fmt) != ARCHIVE_OK) goto cleanup;
    if (archive_write_add_filter_by_name(a, flt) != ARCHIVE_OK) goto cleanup;

    // Phase 3: Data-entry setup
    static char out_buf[1 << 20];
    size_t used = 0;
    if (archive_write_open_memory(a, out_buf, sizeof(out_buf), &used) != ARCHIVE_OK) goto cleanup;

    // Phase 4: Entry population
    struct archive_entry *entry = archive_entry_new();
    if (entry) {
        archive_entry_set_pathname(entry, entry_name[0] ? entry_name : "test_file");
        archive_entry_set_filetype(entry, AE_IFREG);
        archive_entry_set_size(entry, (la_int64_t)n);
        if (archive_write_header(a, entry) == ARCHIVE_OK) {
            archive_write_data(a, d, n);
        }
        archive_entry_free(entry);
    }
    archive_write_close(a);

cleanup:
    archive_write_free(a); // Deterministic teardown
    return 0;
}
```

### 4.2 G2: Contextual LLM Engine (PromptFuzz Formulation)
For gap routines requiring multi-struct associations or callbacks:
- **Backend:** `llama.cpp` hosting `Qwen2.5-Coder-7B-Instruct-Q4_K_M` locally via OpenAI-compatible endpoints (`http://localhost:8080/v1`).
- **Prompt Structure:**
  1. System context & memory invariants (no heap leaks, check every pointer return).
  2. Concrete target symbol and signature.
  3. Neighboring dependency prototypes derived from the P->C call graph.
  4. Real-world usage snippets mined directly from `libarchive/test/*.c`.
- **Repair Feedback Loop:** On O1 compilation error, stderr logs are prepended to a follow-up prompt for 1 automated correction pass.
- **Cache Invariant:** All LLM outputs are hashed by `SHA256(Prompt + Model + Seed)` and stored in `llm_cache/` for 100% offline, deterministic reproducibility.

## 5. Stage 3: Correctness Oracles Detail

| Oracle | Execution Mechanism | Pass Criteria | Reject Consequence |
| :--- | :--- | :--- | :--- |
| **O1: Compilation** | `clang -fsanitize=address,undefined,fuzzer -Werror=implicit-function-declaration` | Exit code 0, 0 compilation errors. | Reject immediately or trigger G2 repair loop. |
| **O2: Sanity Run** | Execute 60 seconds against known-valid corpus files (`test/*.tar.gz`, etc.). | Zero ASan/UBSan crash reports, clean process exit. | Reject: Crash on valid input indicates harness API misuse. |
| **O3: Gap-Hit** | Export coverage via `llvm-profdata` and `llvm-cov export`. | Execution count of target gap function $\ge 1$. | Reject: Harness bypassed target routine. |
| **O4: Static Lint** | AST traversal over candidate C source code. | Parity between `*_new` and `*_free`; all pointer returns checked before dereference. | Reject: Violates memory lifecycle invariants. |

## 6. Stage 5: Greedy Set-Cover Selection

```python
def select_diverse_harnesses(candidates, max_k=16):
    selected = []
    uncovered_gap = set(load_gap_functions())
    
    while len(selected) < max_k and uncovered_gap:
        best_candidate = None
        best_gain = set()
        
        for cand in candidates:
            if cand in selected:
                continue
            cand_coverage = get_executed_gap_functions(cand)
            gain = cand_coverage.intersection(uncovered_gap)
            if len(gain) > len(best_gain):
                best_gain = gain
                best_candidate = cand
                
        if not best_candidate or len(best_gain) == 0:
            break # No further marginal gap coverage gain
            
        selected.append(best_candidate)
        uncovered_gap.difference_update(best_gain)
        
    return selected
```
